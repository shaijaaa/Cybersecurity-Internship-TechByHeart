## Metasploit Framework

Metasploit is a penetration testing framework used by cybersecurity professionals to test vulnerabilities in authorized environments.

### Commands Practiced

Launch Metasploit:

```bash
msfconsole
```

Search for modules:

```bash
search vsftpd
```

Select a module:

```bash
use exploit/unix/ftp/vsftpd_234_backdoor
```
