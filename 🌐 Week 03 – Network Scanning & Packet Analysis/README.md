## Nmap – Network Scanning

Nmap is a network scanning tool used to discover devices, identify open ports, and detect running services.

### Commands Practiced

Check Nmap version:

```bash
nmap --version
```

Host Discovery:

```bash
nmap -sn 192.168.1.0/24
```

Port Scanning:

```bash
nmap 192.168.1.10
```
